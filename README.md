## 🎯 Проблема, которую решает проект

Изучение иностранных слов — это долгий и сложный процесс. Традиционные методы (зубрежка, простые карточки) неэффективны, потому что:

- ❌ **Забывание происходит быстро** — без правильного интервала повторений 80% информации забывается за месяц
- ❌ **Нет персонализации** — все учат одинаково, независимо от индивидуальных особенностей памяти
- ❌ **Нет мотивации** — сложно отслеживать прогресс и видеть результаты
- ❌ **Неудобный интерфейс** — старые методы не адаптированы под современные устройства

**Grable решает эти проблемы**, используя научно обоснованный алгоритм FSRS для оптимального планирования повторений и современный интуитивный интерфейс.

## ✨ Основные возможности

### 🎓 Интеллектуальное изучение слов

- **FSRS алгоритм** — автоматический расчет оптимальных интервалов повторений на основе кривой забывания
- **Адаптивное обучение** — система подстраивается под вашу скорость запоминания
- **Три режима ответа**: "Не знаю", "Повторить", "Знаю" — для точной оценки вашего уровня
- **Ежедневная норма** — настраиваемое количество новых слов в день (5-30 слов)

### 📱 Современный интерфейс

- **CardStackView** — интуитивные свайпы для изучения карточек
- **Визуальные оверлеи** — цветовая индикация при свайпах (красный/желтый/зеленый)
- **Flip-анимация** — переворот карточки для просмотра перевода и примеров
- **Прогресс-бар** — отслеживание прогресса в реальном времени
- **Темная и светлая темы** — поддержка обоих режимов оформления

### 📚 Управление словарем

- **Плейлисты (категории)** — организация слов по темам (Еда, Семья, Профессии и т.д.)
- **Пользовательские категории** — создание собственных коллекций слов
- **Категория "Свои слова"** — персональный словарь для пользовательских слов
- **Добавление слов** — возможность добавлять новые слова с примерами и транскрипцией
- **Редактирование категорий** — выбор категорий для включения в обучение

### 📊 Статистика и прогресс

- **Детальная статистика** — количество выученных, изучаемых и повторенных слов
- **Временные периоды** — статистика за 7, 30, 90 дней и за все время
- **Визуализация прогресса** — графики и диаграммы для наглядного отображения результатов
- **Ежедневные достижения** — отслеживание ежедневной нормы изучения

### 🔔 Умные уведомления

- **Напоминания о повторениях** — автоматические уведомления о словах, которые пора повторить
- **Настраиваемое время** — выбор удобного времени для получения напоминаний
- **Deep linking** — переход в приложение прямо из уведомления

### 🌍 Локализация

- **Русский и английский** — полная поддержка двух языков интерфейса
- **Plurals** — корректное отображение множественных форм слов

## 🛠 Технологический стек

### Core Technologies

- **Kotlin** — основной язык разработки
- **Android SDK** — минимальная версия: API 26, целевая: API 36
- **Gradle** — система сборки с использованием Version Catalog

### Architecture & Patterns

- **Clean Architecture** — разделение на слои: UI, Domain, Data
- **MVVM (Model-View-ViewModel)** — архитектурный паттерн для UI
- **Unidirectional Data Flow** — однонаправленный поток данных
- **Modular Architecture** — модульная структура проекта

### Dependency Injection

- **Koin** — легковесный DI-фреймворк для Kotlin

### Database

- **Room** — абстракция над SQLite для локального хранения данных
- **Migrations** — поддержка миграций базы данных (версия 3)

### UI/UX Libraries

- **Material Design Components** — современные UI компоненты
- **CardStackView** — библиотека для свайпаемых карточек
- **ViewBinding & DataBinding** — привязка данных к представлениям
- **ConstraintLayout** — гибкая система верстки
- **MPAndroidChart** — библиотека для построения графиков статистики

### Reactive Programming

- **Kotlin Coroutines** — асинхронное программирование
- **Kotlin Flow** — реактивные потоки данных

### Background Tasks

- **WorkManager** — управление фоновыми задачами (уведомления)

### Image Loading

- **Coil** — загрузка и кэширование изображений

### Text-to-Speech

- **Android TTS** — встроенный синтез речи для произношения слов

### Networking

- **Custom Network Module** — модуль для синхронизации данных с сервером

### Algorithm

- **FSRS (Forgetting Curve Spaced Repetition System)** — алгоритм интервальных повторений, разработанный Jarrett Ye

```
Grable/
├── app/                    # Главный модуль приложения
├── core/                   # Базовые модули
│   ├── database/          # Room база данных, DAO, Entity
│   ├── design/            # Общие стили, темы, ресурсы
│   └── navigation/        # Навигация между экранами
│       ├── api/           # API навигации
│       └── impl/          # Реализация навигации
├── feature/               # Функциональные модули
│   ├── home/              # Главный экран
│   ├── learn/             # Изучение слов (FSRS)
│   ├── playlist/          # Управление категориями
│   ├── add_word/          # Добавление новых слов
│   ├── progress/          # Статистика и прогресс
│   └── settings/          # Настройки приложения
└── libs/                  # Внешние библиотеки
    ├── fsrs/              # FSRS алгоритм
    ├── di/                # Dependency Injection (Koin)
    ├── network/           # Сетевой слой
    ├── imageloader/       # Загрузка изображений
    └── tts/               # Text-to-Speech
```

### Слои архитектуры

Каждый feature модуль следует принципам Clean Architecture:

```
┌─────────────────────────────────────┐
│           UI Layer                  │
│  (Fragments, ViewModels, Adapters) │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│         Domain Layer                 │
│  (Interactors, Domain Models)       │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│          Data Layer                  │
│  (Repositories, DAOs, Entities)     │
└─────────────────────────────────────┘
```

### Принципы

- **UI знает только Domain** — UI слой не знает о деталях реализации Data слоя
- **Domain знает только Data** — Domain слой знает только интерфейсы Data слоя
- **Repository** — предоставляет "сырые" данные из БД или API
- **Interactor** — преобразует данные Repository в Domain модели
- **ViewModel** — преобразует Domain модели в UI состояние

## 🎨 Основные решения в проекте

### 1. FSRS алгоритм для интервальных повторений

**Проблема**: Как оптимально планировать повторения слов для максимальной эффективности запоминания?

**Решение**: Интеграция алгоритма FSRS (Forgetting Curve Spaced Repetition System), который:

- Рассчитывает оптимальный интервал до следующего повторения на основе кривой забывания
- Адаптируется под индивидуальные особенности памяти пользователя
- Учитывает сложность слова, стабильность запоминания и время последнего повторения

**Реализация**:

- `FSRSService` — сервис для вычислений FSRS
- `FSRSStateEntity` — хранение состояния каждого слова (stability, difficulty, interval, dueDate)
- Автоматический расчет следующей даты повторения при каждом ответе

### 2. Модульная архитектура

**Проблема**: Как организовать код для масштабируемости и поддержки?

**Решение**: Модульная архитектура с четким разделением ответственности:

- Каждая фича — отдельный модуль (home, learn, playlist, etc.)
- API и Implementation разделены для слабой связанности
- Core модули содержат общую функциональность

**Преимущества**:

- Независимая разработка фич
- Легкое тестирование
- Возможность переиспользования модулей

### 3. Реактивное программирование с Flow

**Проблема**: Как эффективно обрабатывать асинхронные данные и обновления UI?

**Решение**: Использование Kotlin Flow для реактивных потоков данных:

- `StateFlow` для UI состояния
- `Flow` для данных из базы данных
- Автоматическое обновление UI при изменении данных

**Пример**: При добавлении нового слова список автоматически обновляется благодаря Flow из Room.

### 4. Умное планирование повторений

**Проблема**: Как не перегружать пользователя и показывать слова в нужное время?

**Решение**: Комбинированный режим обучения:

- Приоритет словам, которые пора повторить (due words)
- Дополнение новыми словами до достижения дневной нормы
- Исключение уже просмотренных слов из текущей сессии

**Реализация**: `LearnInteractor.getSessionCards()` объединяет due words и new words.

### 5. Персистентность прогресса

**Проблема**: Как сохранить прогресс пользователя при закрытии приложения?

**Решение**: Многоуровневая система сохранения:

- **Room Database** — долгосрочное хранение FSRS состояний и статистики
- **SharedPreferences** — сохранение дневного прогресса (learnedCount, reviewedCount)
- Автоматическое восстановление прогресса при возврате в приложение

### 6. Фоновые уведомления

**Проблема**: Как напомнить пользователю о необходимости повторения слов?

**Решение**: WorkManager для фоновых задач:

- Периодическая проверка слов, которые пора повторить
- Настраиваемое время уведомлений
- Deep linking для быстрого перехода к обучению

### 7. Локализация и интернационализация

**Проблема**: Как сделать приложение доступным для разных языков?

**Решение**: Полная поддержка локализации:

- Отдельные `strings.xml` для русского и английского
- Plurals для корректного отображения множественных форм
- Локализованные уведомления и сообщения

## 📖 Кулстори

### От идеи к реализации

**Grable** родился из личного опыта разработчиков, которые столкнулись с проблемой эффективного изучения иностранных слов. Традиционные приложения-карточки не учитывали научные принципы запоминания, а существующие решения с интервальными повторениями были либо слишком сложными, либо недостаточно гибкими.

### Вызов: FSRS интеграция

Одним из самых интересных технических вызовов стала интеграция алгоритма FSRS. Это не просто "повтори через 3 дня" — это сложная математическая модель, которая учитывает:

- Кривую забывания Эббингауза
- Индивидуальные параметры памяти
- Адаптацию под сложность конкретного слова

Пришлось глубоко изучить алгоритм, адаптировать его под Android и интегрировать с Room базой данных. Результат — система, которая действительно помогает запоминать слова эффективнее.

### Модульная архитектура как философия

Решение использовать модульную архитектуру было принято не сразу. Изначально проект был монолитным, но по мере роста функциональности стало ясно, что нужна более гибкая структура. Рефакторинг занял время, но результат того стоил — теперь каждая фича может разрабатываться независимо, код стал чище и понятнее.

### Пользовательский опыт

Особое внимание было уделено UX. Свайпы карточек, визуальные оверлеи, плавные анимации — все это создает ощущение современного, приятного в использовании приложения. Мы хотели, чтобы изучение слов было не рутиной, а увлекательным процессом.

### Будущее

Grable продолжает развиваться. В планах — расширение функциональности, добавление новых языков, интеграция с облачными сервисами для синхронизации между устройствами, и, возможно, AI-рекомендации для более персонализированного обучения.

## 🚀 Установка

### Требования

- Android Studio Hedgehog или новее
- JDK 11 или выше
- Android SDK (API 26+)
- Gradle 8.13.2+

### Шаги установки

1. **Клонируйте репозиторий**

   ```bash
   git clone https://github.com/your-username/grable.git
   cd grable
   ```

2. **Откройте проект в Android Studio**

   - File → Open → выберите папку проекта

3. **Синхронизируйте Gradle**

   - Android Studio автоматически синхронизирует зависимости
   - Или выполните: `./gradlew build`

4. **Запустите приложение**
   - Подключите Android устройство или запустите эмулятор
   - Нажмите Run (▶️) или `Shift + F10`

### Настройка

- При первом запуске приложение создаст локальную базу данных
- Настройте количество новых слов в день в Settings
- Включите уведомления для напоминаний о повторениях
